Windows XP - Notas de instalación

  • Interfaz de instalación clásica (texto azul).
  • Particionar con C/D, formatear NTFS.
  • Asegurarse de drivers legacy para chipset y video.

Windows 7 - Notas de instalación

  • Preferible instalación en modo legacy si el hardware no soporta UEFI.
  • Instalar Service Pack y drivers desde el fabricante.

Windows 8 - Notas de instalación

  • Verificar soporte NX, PAE y SSE2 si es en VM.
  • UEFI puede ser requerido en hardware nuevo.

Windows 10 - Notas de instalación

  • Recomendado usar imagen oficial y UEFI 64-bit.
  • Asignar al menos 4 GB RAM para buen rendimiento.

Windows 11 - Notas de instalación

  • Requiere TPM 2.0 y Secure Boot; comprobar firmware.
  • Algunas placas requieren ajustes para habilitar TPM virtual o emulación.

Ubuntu - Notas de instalación

  • Se recomienda usar la versión LTS más reciente.
  • Particionar ext4 y swap según uso.

Preparación de Ventoy

  • Descargar Ventoy y ejecutar en modo administrador.
  • Instalar Ventoy en la unidad USB y copiar ISOs directamente.
